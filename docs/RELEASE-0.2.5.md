# Soundcloud Desktop 0.2.5

## Current SoundCloud tracks on Overview

Overview now includes a **Current tracks on SoundCloud** panel. After the account is connected and its catalog is synced, the panel shows up to five tracks from the latest saved catalog snapshot, with each track's visibility, play count, and likes. It also shows the sync time and offers shortcuts to sync or open the full catalog.

The preview uses the account snapshot returned by the SoundCloud API. Connect and sync again to refresh it. The local Music library remains a separate list of audio files on this PC.

For setup and task instructions, see the [user guide](USER-GUIDE.md).
