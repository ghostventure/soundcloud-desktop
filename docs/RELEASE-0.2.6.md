# Soundcloud Desktop 0.2.6

## More SoundCloud data on Overview

The Overview now adds an account snapshot above the current-track list:

- Follower and account track totals
- Total plays and likes summed across the synced catalog
- Public and private track counts
- The three most-played tracks, with relative play bars and each track's plays and likes

These figures use the latest saved SoundCloud API snapshot. Select **Sync catalog** to refresh them. They are catalog totals, not time-series analytics; open Artist Insights for SoundCloud's detailed analytics.

The current-tracks preview and full catalog remain available below the snapshot and on the SoundCloud page. The local Music library continues to show files on this PC separately.

For connection and workflow instructions, see the [user guide](USER-GUIDE.md).
