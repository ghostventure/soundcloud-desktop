# Startup and first-run profile (0.2.4)

Soundcloud Desktop shows a short splash screen while it loads the local workspace and SoundCloud connection state. Startup errors remain visible with a clear message.

A new, empty workspace asks for an artist or studio name before continuing. Genre, location, and a short bio are optional. The profile is stored in the local workspace and included in metadata backups. Later launches load the saved profile automatically. Existing workspaces with saved tracks, releases, or campaigns skip the first-run prompt.

This is a local artist profile tied to the current Windows user data folder; it is not a password login or a multi-user account system. SoundCloud OAuth remains managed separately by the connected account flow.
